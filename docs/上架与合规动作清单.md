# 上架与合规动作清单

平台规则是硬的：违规扣分直接影响流量和活动资格，一条都吃不起。所以上架的第一原则是**不出错优先于快**。

## 上架前逐项过

### 标题

- [ ] 不含极限词、违禁词、医疗/功效类断言
- [ ] 品牌、型号、规格与实际一致（没有品牌就写「无品牌」或通用名，不蹭）
- [ ] 关键词覆盖买家会搜的说法，但不堆砌到读不通
- [ ] 不与主图承诺冲突（主图写「买一送一」，标题必须有对应说明）

### 类目与属性

- [ ] 类目选最末级、最贴近的（错一个类目，流量就进不来）
- [ ] 必填属性全部填满（缺属性会导致活动报不上）
- [ ] 属性值不夸大（材质、尺寸、容量的虚假标注是最常见的处罚点）

### 图片

- [ ] 首图主体清晰、无牛皮癣文字、无水印
- [ ] 白底/场景图符合类目要求
- [ ] 所有图片里的文字承诺，详情页都要有对应条款

### 价格与库存

- [ ] 到手价 = 标价 - 优惠 - 平台补贴，算清楚再填
- [ ] 库存与真实可发数量一致（超卖会直接扣分）
- [ ] 运费模板按地区设好，偏远地区单独标

### 售后与话术

- [ ] 退换货规则写清楚（7 天无理由/质量问题/运费谁承担）
- [ ] 客服话术与商品页口径一致；改价改库存后先同步话术
- [ ] 常见问题备好标准答案（尺寸/发货时间/能不能便宜）

## 改价与改库存的留痕规矩

每次改动记一行：**谁 / 什么时候 / 改了哪个 SKU / 从多少改到多少 / 为什么改**。

价格可以变，但不能说不清为什么变。这条规矩的价值不在合规，在复盘——三个月后你还能回答「当时为什么定这个价」。
